## 3. 顶会潜力：比首对更有推进理由，但核心主张尚未成立

本轮开始出现有意义的动作差异：case6/4203的C试探答案56、A答案26均错，B答28正确；这个例子更接近“还不能直接输出答案，但摘要后继续可能有用”。同时case8/1084的B破坏了A可恢复的正确性，说明不能无条件摘要。

但有三个关键风险：

1. **长度可能已经解释结果。** 三题最后一个位置的B均更省token，且本轮没有伤害正确性；因此必须与固定晚摘要／长度规则比较。不能看完这九点就宣布H+C必要，也不能把离线单次分叉结果当在线策略回放。
2. **当前H变化没有一致的收益方向。** case6/4203获益时ΔH约+0.0806；case8两个省成本的正确位置为−0.0215／−0.0651。最早位置ΔH=0是参考定义，不是观测到熵稳定。case8这两点归一化H下降时，原始熵和反而增长6.33%／10.76%，需要控制log长度归一化效应。
3. **有些摘要收益可能被直接早停替代。** case8的两个中后段位置，C试探已经答对。需要比较直接作答的成本与可靠性，不能只和继续推理比。C也受格式token影响，不是语义正确概率。

因此，我会继续这个方向的下一轮小验证，但不会据当前数据建议直接扩大到昂贵的完整论文实验。顶会贡献需要在ASAG已有联合信号、InftyThink+已有时机对照的基础上，证明H+C对摘要动作条件收益有额外预测价值，并在未见题上计入全部成本仍有收益。完整论文定位与决策条件见[SCIENCE_REVIEW_zh.md](SCIENCE_REVIEW_zh.md)。
