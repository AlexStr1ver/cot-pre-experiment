## ASAG 的动作，以及本 idea 仍可能增加什么

第 5 页 §4.1–4.3 和第 13 页 Algorithm 1 给出以下机制：首次 ATP 仅凭 `C > λ` 可以退出；后续需 `C > λ 且 ΔH < α`。退出动作是插入 `</think>` 后进入答案阶段，伪代码并非直接提交 probe 答案。`C < λ 且 ΔH < α` 时，Eq. (7) 将当前输出概率与中间答案的归一化概率按 0.95/0.05 混合；虽然名称是 logits injection，不能误写为未经 softmax 的 logits 相加。`ΔH > α` 时再检查上一 thought 与当前 thought 的平均 attention，满足条件则追加 jump prompt，超过次数限制后结束推理。

jump prompt 是在旧上下文中追加改变思路的文字；它没有执行“生成摘要 → 丢弃旧历史 → 用摘要重建上下文”。因此，**免训练 H/ΔH 与 C 联合判断本身已有直接先例；潜在新增点是它能否选择有条件净收益的摘要／重置动作**。高 C、低 ΔH 的状态可能更适合直接作答，不能自动解释成应当摘要。后续需分别评价直接结束、继续、摘要后继续三种选择，避免将答案已就绪与进展可压缩混为一谈。

仍需标明原文的实现不确定性：第 8 页 logits injection 消融段误写为 `C > λ`，而 §4.2 与 Algorithm 1 一致写 `C < λ`；Algorithm 1 的 `jump_count <= s` 与正文“最多 s 次”的边界不完全一致；probe 停止和答案概率 token 范围、多 token 概率注入的确切聚合规则没有完整规定。没有作者实现级核验前，不声称严格复现。

## 研究判断

原始方向仍值得进行小规模验证；此次停止没有提供联合信号方案失败的证据。顶会潜力目前未被证实。下一项实质证据应为：在控制前缀长度、推理阶段和计算预算后，联合信号能否比原生摘要、固定／随机位置、H-only、C-only 以及同模型的早停替代，更好地识别“摘要后继续”的净收益；所有监测、probe、摘要与重置 prefill 成本都应计入。9 个位置只够做技术与信号可读性检查，不能作为统计性能结论。
