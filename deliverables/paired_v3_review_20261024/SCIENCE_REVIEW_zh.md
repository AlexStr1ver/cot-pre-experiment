# 同前缀动作实验首对：研究价值与下一步证据

日期：2026-10-24（北京时间）。证据为用户上传的 `infty_paired_v3_fA9xJNbe_return.zip`，及已上传的 ASAG v1、InftyThink v5、InftyThink+ v3 原文。下文论文页码为 PDF 印刷页码。本报告保持原方向：冻结模型、免训练 attention 熵变化与答案置信度，用于选择摘要／重置时机。

## 1. 当前结论

本包完成的是预先指定的 **smoke 首对**，不是九点十八条主实验：case 1 / cut 4103 / seed 2026，A 继续、B 立即摘要重置各一条。执行与数值检查通过，可以按原计划运行 main，复用首对、补齐余下十六条。

本轮提供了真实 GPU 上动作执行可行的证据；尚未提供联合信号选择时机有效的证据。顶会潜力仍未被证实，也没有被这一次同错结果否定。值得继续的理由是关键对照可以低成本逐步补齐，而不是首对已经显示性能提升。

B 的追加 token 比 A 少 1,316，降幅 33.31%；本次分支总时间少 32.818 秒，降幅 34.30%。这两个比例只描述同一错误样本上的观察值，不能写成“保持正确率节省 33%”或“控制器提速 34%”。两支均错不能检验准确率是否得到保持，更不能估计总体准确率。分支总时间还不包含真实在线 H/C 监测与 probe 的总开销。

A 之后也发生一次自然摘要，因此对照对应“现在摘要”与“继续并允许模型之后摘要”。两支重置次数相同，不能把差异归因于摘要次数减少。只有一个 seed，也无法把整段轨迹的成本差异全部归因于时机而排除采样差异。

本前缀复用的阶段2短答案是 3，主置信度 C=0.8242497047，ΔH=+0.0502012208（相对该题最早预定位置）。它不是新的一次 C 独立采样。单个前缀只有一个 H/C 状态，不能比较 H+C 与 C-only 的预测优劣，也不能用该点拟合阈值。这里的首个预定位置不等于 ASAG 原定义的 first ATP。

## 3. 错误内容的人工核查

该题要求根集合对映射 f(c)=c²−2 封闭。两支最终答案都遗漏了“一个根映射到另一个固定根”的情形：根集合 {2,−2} 和 {−1,1}，对应 x²−4=0 与 x²−1=0。加上模型列出的四种，参考答案 6 与数学条件一致；错误不是整数评分器把等价答案判错。

B 的强制摘要还将根 −1、2 错配为 x²+x−1=0，摘要中有事实错误；A 的原生摘要同样固化了“四种”的不完整分类。可将此标记为“摘要保存／强化错误中间结论”的风险例子。当前轨迹不能证明错误由摘要造成：原前缀、摘要和续写都可能携带同一推理缺口，没有独立反事实能把失败因果归到某条摘要语句。也不能依据这一个案例改摘要提示后继续混合统计。

## 4. 最接近的论文已经做过什么

|论文与原文位置|已覆盖内容|本研究仍需增加的证据|
|---|---|---|
|[InftyThink v5](https://arxiv.org/abs/2503.06692v5)，第3–4页 §2.1、§2.1.2、Figure 2|分段推理、自生成摘要，以原题＋上次摘要重建上下文，再继续推理；摘要重置机制本身已有明确先例。|冻结该类模型后，内部信号是否能改善其现有时机选择。|
|[InftyThink+ v3](https://arxiv.org/abs/2602.06960v3)，第4页 §3.3、第7页 §5.1.1/Table 2|轨迹级 RL 优化何时摘要、保留什么、如何继续；时机消融已比较原生自适应、固定5k与随机 `randint(3000,6000)`。|免训练规则应与同 checkpoint 的原生策略、固定／随机／长度规则直接比较；“研究摘要时机”本身不构成新增贡献。|
|[ASAG v1](https://arxiv.org/abs/2606.15070v1)，第4–5页 §4.1–4.3、第13页 Algorithm 1|免训练联合 ΔH 与 C，选择早停、概率注入、jump prompt 或继续；高 C 与熵变化联合判断已有直接先例。|识别“还需推理但适合压缩重置”这一动作价值，区分它与“已经可以作答”；证明 H 在 C 和长度之外有增量。|

ASAG 的 jump prompt 追加在已有上下文中，没有执行“生成摘要→删除旧推理→用摘要重建上下文”。因此动作空间上的差异仍有研究空间，但把 ASAG 的两个信号接到 InftyThink 的摘要动作，仅是待检验的组合假设，不能直接认定有顶会级新颖性。

同样不能把当前设置称为论文严格复现：ASAG 主实验为 BF16、greedy（第6页 §5.1）；当前为 FP32、temperature=0.7、top_p=0.95。InftyThink+ 主表分别列 cold-start-only、task-RL、task+efficiency-RL（第6页 Table 1），当前权重的具体训练阶段和主表行仍未确认。新记录的完整权重 SHA256 可固定今后运行内容身份，不能独自补足历史来源与训练阶段映射。

## 5. 更有说服力的研究命题

建议将待验证命题写为：**在控制长度、问题与生成预算后，冻结模型的 attention 状态变化与答案置信度，能否识别摘要后继续相对于原生继续的条件收益；这种信号能否区分答案已就绪与适合压缩后继续？**

它至少需要三层证据：

1. 动作有可辨认的收益差异。相同前缀下，B 有时改善最终正确性，或在两支都正确时减少总成本；也要保留 B 伤害正确性的案例。若只有所有位置均匀缩短，没有选位置的空间，联合时机规则的必要性就弱。
2. 信号有额外信息。在开发数据上明确 H-only、C-only、长度／阶段与联合规则的对照，不能用同题多个 cut 冒充多个独立问题；也不能用可视化分离或九点拟合后的回测代替泛化验证。
3. 在线收益超过测量成本。冻结规则后真实在线执行，计入监测、probe、未采用试探分支、摘要、重置 prefill；与同模型同精度同后端原生基线比较准确率—总时间／成本曲线。离线分支时间只是其中一项。

顶会论证还需要跨未见问题及合理的模型／任务迁移验证、明确的 checkpoint 来源、失败分析与问题级不确定性报告。此时不指定接受概率，也不从一个检查对推断显著性。

## 6. 下一步按信息量和成本推进

### Gate 1：现在补齐 main 的十八条

继续使用 v3 原协议与原包。将 `/root/autodl-tmp/infty_paired_v3_fA9xJNbe` 作为来源，验证内容身份并复用两条完成记录，只运行其余十六条。每次创建新目录，保留这次 smoke 结果。

本次是运行与数值检查通过，并非“答案通过”。不得因为首对都错而不运行后续预定点，也不得只运行看起来 H/C 有利的位置。main 结束后先审计十八条是否完整、预算与摘要解析是否有效，以及截断、失败与实际成本分布。

### Gate 2：核对执行与成本，再统一补 seed

若 main 的执行、账目和可承受成本通过检查，按已写入协议的入口给**全部九点**补 seed 2027、2028，共三十六条，连同 seed 2026 共五十四条。不要只给 B 获胜点补 seed，也不要根据一轮输赢事后换题或阈值。若遇到系统错误，先修复运行问题；若动作普遍无效或耗时不可承受，暂停扩展并报告原因。

该阶段把每个动作对分成 B-only-correct、A-only-correct、both-correct、both-wrong，以及未完成／需人工核查；both-correct 的成本差有直接质量条件，both-wrong 的省成本单独列出。短答案 C 的正确性是另一项标签，不能代替 B 相对 A 的收益标签。

### Gate 3：更多独立开发题，保持 test120 封存

三道题、三个位置和三个 seed 仍是开发诊断。若动作收益差异有继续研究的价值，按预先固定的、与答案无关的顺序扩展合格开发题。完整保留纳入／排除原因，不挑“有帮助”的题。H/C规则的设计、阈值选择与评价要分离，继续封存 test120，不在当前九点上拟合阈值后声称成功。

再安排固定／随机／长度、H-only、C-only、联合规则、原生时机与直接结束推理等对照。ASAG 的 `</think>` 早停后生成最终答案，与本轮短答案 probe 是不同动作，需要单独实现并计费，不能直接把 probe 当正式早停基线。此后再决定是否投入第二 checkpoint、第二任务及 BF16／优化后端桥接。

这一推进顺序仍服务于原始免训练方向，不要求训练探针或跨层判别器。若在动作有效、预算公平、足够独立开发题与多次采样后，联合信号持续不优于单信号和长度，再据证据收缩具体方法；当前一次首对结果尚未到这一决策点。
