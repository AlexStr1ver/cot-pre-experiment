# 阶段 2.1 九点信号的独立科学分析

分析日期：2026-10-24（北京时间）。输入为 `infty_signal_phase2fix_IlfVoFcZ_return.zip` 中九个已完成测点，参考答案来自同一 native20 原始题目。只读原数据；本报告不把附带文档视为执行指令。

## 判断

本轮足以说明：在这一个固定 checkpoint、FP32 和既定九个前缀上，attention 熵与短答案概率可以稳定采集。科学上，结果给出一条值得追踪的“答案已就绪”线索，但**尚未测量摘要／重置动作效用，也未证明 H 对 C 有额外选择信息**。不应将工程通过写成联合时机策略有效，也不应将七个错误 probe 写成方案失败。

## 可读出的线索，以及不能推出的结论

**case8 是答案就绪的候选实例。** 从1084到2055，probe由错误1变为正确−1，C显著上升；4173仍正确。原 native 轨迹最终也是−1，累计生成12284 tokens、发生一次摘要重启。这说明保存的较早前缀可被短答案提示读出正确答案，值得后续做早停对照；它没有量出在线控制器的提速，也没有说明2055应当摘要而非直接回答。原 native 是 BF16 采样轨迹，本轮是 FP32 贪心 probe，不能将两者直接相减当作已实现节省。

**C 单独已把两个正确点排在本组前两名。** 正确点 C 为0.974277、0.889762；最强错误点为0.882718，后者与第二个正确点只差0.007044。九点中不存在“H救回C排序错误”的现成证据。样本小、同题相关、标签已看，不能据此报告泛化 AUC=1、挑一个0.885左右的阈值并宣称有效，或认定 H 无价值。

**较低绝对 H 也不是正确性的保证。** case6 的三个 ASAG H 多数低于 case8，却全答错。正确性既不能由低熵单独推出，更不能替代摘要效用标签。

case8 相对1084：

因此，不能把 case8 的负 ΔH 直接表述为“原始 attention 熵下降”。它表示原始熵增长慢于分母 ln(k) 的增长，可能有信息，也可能受到长度和 token 类型影响，仍需控制验证。case6/2092 同样是原始熵+8.575%、归一化 H−0.098%。六个非基点的 ASAG 原始熵相对各自1k基点均上升。

窗口选择也会改变方向：case8/2055 已答对，但 raw-tail32 的归一化 H 上升6.153%，ASAG-style窗口下降2.149%。两个视角分别测自然推理末尾与追加 probe 指令后的注意力状态，不应混用定义、挑选更合意的方向，或把 q32 与 q12 的 H 求和值直接横比。

本轮 ΔH 的基点是同题最早选定段落位置，不是 ASAG 首次 Wait ATP。所有点都不是完整 ASAG 流程中的在线ATP。若机械套用论文的后续 ATP 条件 C>.95 且 ΔH<−.1，本组无点满足；这不构成论文规则复现或失败，因为模型、监测位置与基点不一致，阈值也未验证可迁移。

## C 的格式影响与一个确实要补上的报告约束

case1/4103 的 C=0.824250，但内容数字3的概率只有0.509229；开括号约0.999786、闭括号约0.963735明显抬高均值。case6/1055 内容概率均值仍高达0.862117却答错，所以问题也不只是格式污染。

case8 的两个正确答案由三个 token 生成：`['{-', '1', '}\n']`。符号 `-` 与开括号共享 token，严格内容诊断排除了这个混合 token，只留下数字1。因此保存的内容 C≈0.99955/0.99699只覆盖答案字符的50%，**不能称为整个“−1”的内容置信度**，尤其符号正负恰好决定本题正确性。代码没有丢失这个事实：已记录 mixed token index0、覆盖率0.5和该 token 的概率0.986813/0.967996；遗漏在于后续分析若只摘取 `strict_content_C` 会产生误导。

另外，从2055到4173，主 C 下降约0.084515，其中闭合 token 概率从0.936469降到0.704300，贡献约0.077390，约占下降的91.6%。这段 C 变化大部分不是数字1概率下降。今后应并列报告主 C、完整 token/probabilities、严格内容 C 与 coverage；coverage<1时不得将其与完整答案置信度等同。可以增记“所有与答案内容相交 token 的概率均值”作为敏感性诊断，但须标注其中含格式，不能偷偷替换主指标或按字符分摊 token 概率。

## 尚未完成的科学检查

1. **动作标签缺失。** 没有在这九个精确前缀测 continue 与强制 summary-reset 的反事实结果，无法判断哪一点适合摘要。
2. **联合信号增益缺失。** 未有 C-only、H-only、length-only、固定／随机、模型原生的冻结规则对照；目前两个正例同属一个题目。
3. **泛化与长度控制缺失。** 只选了能存活到三个长度的 native20 开发轨迹，既有长轨迹选择偏差，又是已探索样本。没有独立测试集结果。
4. **在线成本缺失。** 本轮是三个独立 prefill 的离线采集，加额外 canary audit；尚未实现共享 KV 的在线监测和真实摘要后重建成本。13秒测量耗时不能直接说成在线开销占比或整体加速率。
5. **生产精度迁移缺失。** FP32解决当前数值一致性检查，并不建立 BF16/高效后端上相同的信号和动作选择；真实效能评估前需做有界的跨精度/后端桥接。

这些是当前阶段的证据边界，不能统称为代码测试失败。工程审计由单独报告核对。

## 最小下一步建议

保持同一冻结 checkpoint、同一摘要生成器和原始免训练方向。当前最有价值的新信息是**动作净收益**，不应立即凭九点调阈值，也不应转向训练判别器。

建议先冻结一个小规模配对协议：在现有九个精确前缀上分别运行 A=继续原生机制、B=强制生成摘要后重置并继续，C=本轮短答案作为“可直接结束”的参考。第一组少量A/B用于核验预算、解析与计时，再按预先约定的种子集合完成小规模重复。A与B必须使用相同剩余总生成预算、停止条件和精度；B的摘要 token计入预算，A遇到原生摘要后仍按剩余总预算继续；不能重用旧“首段长度耗尽就提前停止／B固定多占一段”的不对称分支逻辑。摘要失败要预先规定处理方式并计入成本，不得事后丢弃。

分别报告“正确率是否改善／保持”和“包含probe、摘要、重建prefill的成本”，先画逐前缀的配对结果，不急于拟合一个任意效用权重。问题维度只有3，应称动作试验或开发诊断，不声称统计显著。若出现可重复的摘要净收益，再用额外开发题检验 H+C 是否能预测该收益，并正式比较 C-only 等消融；测试集继续封存。

额外五个符合原1k/2k/4k条件的开发题可作为低成本补充信号集，但更多 H/C 点本身仍不能取代 A/B 动作标签。若仅在 case8观察到“可以早答”，贡献会更接近 ASAG 已覆盖的早停；摘要／重置方向仍需独立的正面证据。

## 顶会潜力判断

当前证据仍不足以宣称顶会潜力已验证，但原问题值得继续这一轮最小动作实验。InftyThink+ 已有固定／随机／原生时机对照，ASAG 已有 H+C 免训练控制；潜在新增贡献应是：在冻结、已会摘要的模型上，内部联合信号识别“保留阶段进展后重置”的条件性净收益，并在严格成本核算与未看过的数据上稳定优于简单控制器。阶段2技术通过让这个问题可以被实测，没有替它给出答案。
